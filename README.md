# Ever After Events – Wedding Planner Website

A responsive website for a wedding and commercial event planning business, built with HTML5, CSS3 and JavaScript.

**Live demo:** https://rehnuma-patel.github.io/wedding-planner-website/

## Sections
- **Home** – hero banner with animated statistics
- **About** – business profile
- **Services** – planning services and animated skill bars
- **Portfolio** – recent events with category filter (Weddings / Corporate / Celebrations)
- **Testimonials** – client review slider
- **Experience** – education and work timeline
- **Contact** – accessible enquiry form with validation

## Features
- Responsive layout with a mobile hamburger menu
- Smooth scrolling and active link highlighting
- Scroll reveal animations and hover effects
- Semantic, accessible form (`<form>`, `<fieldset>`, `<legend>`, `<label>`, `aria-describedby`, `aria-live` error messages)
- Client-side validation: required fields, email format, phone pattern, future date, guest count, character counter
- Respects `prefers-reduced-motion`

## Technologies
HTML5 · CSS3 (Grid, Flexbox, custom properties) · JavaScript (DOM manipulation, IntersectionObserver) · VS Code

## Run locally
Open `index.html` in any web browser.
